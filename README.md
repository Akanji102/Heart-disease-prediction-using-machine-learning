# Heart-disease-prediction-using-machine-learning
❤️ Heart Disease Prediction System

A machine learning-powered system to predict the likelihood of heart disease based on clinical and lifestyle features.

📖 Overview

Cardiovascular diseases remain one of the leading causes of death worldwide 🌍. Early prediction can save lives.
This project leverages machine learning techniques to analyze patient health records and predict the risk of heart disease.

With this system, healthcare professionals and researchers can quickly assess patients’ health risks and make data-driven decisions.

✨ Features

✅ Predicts heart disease risk based on patient data
✅ Supports classification models (Logistic Regression, Random Forest, SVM, etc.)
✅ Clean & well-documented code
✅ Modular pipeline for easy experimentation
✅ Scalable for deployment (Flask/FastAPI integration ready 🚀)

📊 Dataset

The model was trained and tested using the UCI Heart Disease Dataset, which contains key clinical features like:

Age

Sex

Resting Blood Pressure

Cholesterol Level

Maximum Heart Rate Achieved

Exercise Induced Angina

ST Depression (Oldpeak)

And more…

Programming Language: Python 🐍
